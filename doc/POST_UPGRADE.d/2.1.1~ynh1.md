Migrating from dato 1.x to 2.x implies a change in dato config files syntax.
The migration should be automatic but if you encounter some issues with it please report it to [the dato_ynh issue tracker](https://github.com/YunoHost-Apps/dato_ynh/issues).

If the migration didn't happen properly you should be able to manually make the necessary changes with the following operation:
  - run `yunohost app shell dato`
  - cd `sources/config/`
  - open `private.js` and replace `module.exports =` by `export default`
  - open `public.js` and replace `module.exports =` by `export default`
  - restart the dato service `yunohost service restart dato`

Please still report this or any issue you're having so that it can be resolved :)
